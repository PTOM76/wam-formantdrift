Formant Drift

A Web Audio Module (WAM2) effect. Three formant-like peaks slowly and randomly wander over time, so a voice keeps changing its vowel color.
It is not tied to any host. Any host that supports WAM2 can load it.

Use it

Give this URL to a WAM2 host: 
https://ptom76.github.io/wam-formantdrift/index.js
◯ descriptor.json | Source (GitHub) | WeVocal Plugin Packages

Parameters

Peak   0 - 24 dB    Height of the peaks
Sharp  0.3 - 3      Sharpness of the peaks (multiplier of Q)
Drift  0 - 1        How far the peaks wander (1 = the whole range)
Rate   0.02 - 3 Hz  How often a new target is chosen
Mix    0 - 1        Amount of the effect

How it works

Three peaking filters sit in the ranges of the vowel formants (F1 280-900 Hz, F2 800-2700 Hz, F3 2300-3600 Hz).
A looping random waveform moves each filter's frequency smoothly, on the audio thread, so it also works in offline rendering.
